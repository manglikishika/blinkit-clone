
# Blinkit Clone – Online Grocery Delivery Website

A responsive frontend clone of the Blinkit grocery shopping website, built using **HTML5 and CSS3**. This project recreates the look and feel of an online grocery delivery platform with promotional banners, product categories, personal care sections, and product cards.

---

## Live Demo

🔗 **GitHub Repository:**  
https://github.com/manglikishika/blinkit-clone

## Project Preview

A clean and modern grocery shopping interface inspired by Blinkit's design.

### Homepage Features
- Blinkit-inspired navigation header
- Delivery location and estimated delivery time
- Search bar UI
- Promotional grocery banner
- Pharmacy, pet care, and baby care promotional cards
- Grocery category section
- Personal care and daily essentials
- Product cards with prices and Add buttons

## How to Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/manglikishika/blinkit-clone.git
```

**2. Open the project folder**

```bash
cd blinkit-clone
```

**3. Open in VS Code**

```bash
code .
```

**4. Run the website**

Open `index.html` in your browser or use the Live Server extension in VS Code.

## Current Limitations

This project currently focuses on frontend design.

- Search functionality is not connected to a product database.
- Login and cart buttons are visual elements.
- Add buttons do not currently update a shopping cart.
- No backend or payment integration is included.
